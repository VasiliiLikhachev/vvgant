# CLAUDE.md — vvgant

## Стек
- Next.js 14 (App Router), TypeScript, Tailwind CSS
- Supabase (Postgres + REST API + Auth + RLS)
- Хостинг: localhost → Vercel

## Что это
Внутренний инструмент для PR/продуктовой команды ВкусВилл.
Визуализация и управление запуском продуктов в формате Ганта.
15+ продуктов одновременно, у каждого один процесс из ~28 этапов.
У каждого продукта несколько производителей — продукт дробится на подпотоки.

## Модель данных

templates (id, name)

template_tasks (id, template_id, name, duration_days, starts_after → template_tasks.id, order)

products (id, name, image_url)

manufacturers (id, product_id, name)

roles (id, name)  -- справочник: Бренд, Технолог, Продакт...

people (id, name, role_id → roles.id)

tasks (
  id, product_id, manufacturer_id, template_task_id,
  plan_start, plan_end,
  fact_start, fact_end,
  status,  -- 'Не начата' | 'В процессе' | 'Готово' | 'Задержка'
  updated_at
)

task_assignees (task_id → tasks.id, person_id → people.id)

## Роли пользователей
- Админ: редактирует шаблон, создаёт продукты, меняет плановые даты
- Пользователь: меняет статусы, вносит фактические даты
- Реализуется через Supabase Auth + RLS

## UI — Гант

### Колонки таблицы
- Задача (текст, с переносом, не обрезать)
- Статус (дропдаун)
- Дата начала план (отключаемая колонка)
- Дата конца план (отключаемая колонка)
- Ответственный (отключаемая колонка, берётся из people через task_assignees)
- Гант-бар (основная колонка)

### Гант-бар
- Плановая полоска: высота 20px, цвет продукта, z-index снизу
- Фактическая полоска: высота 12px, цвет статуса, поверх плана, opacity 0.68
- Статусные цвета:
  - Не начата: #B4B2A9
  - В процессе: #378ADD
  - Готово: #1D9E75
  - Задержка: #E24B4A
- Цвета продуктов: П1=#378ADD, П2=#1D9E75, П3=#D85A30 (далее по палитре)
- Вехи: ромб
- Сетка по дням, выходные подсвечены жёлтым
- Заголовок таблицы фиксированный (sticky) — при скролле остаётся видимым
- Шкала дат над гант-барами — отдельная строка с метками дат, синхронизирована с барами
- Линия сегодня: красная вертикальная

### Тултип на баре
- Название задачи
- Факт: дата начала — дата конца
- План: дата начала — дата конца
- Продукт, производитель
- Ответственный (роль + имя)
- Статус с цветовым бейджем

### Группировка
Два режима (таб-переключатель):
- По продукту: Продукт → Производитель → Задачи
- По производителю: Производитель → Задачи

### Картинки продуктов
- Маленькая иконка в шапке группы
- Полноразмерное фото в тултипе при наведении на название
- URL хранится в products.image_url

### Фильтры
- Живут в заголовках колонок (иконка воронки в th)
- Клик → дропдаун с чекбоксами
- Меню не закрывается до кнопки Применить / Сбросить
- Мультивыбор: продукты, этапы, ответственные

## Редактор шаблона (/template)
- Таблица этапов: название, длительность в днях, starts_after (дропдаун)
- CRUD этапов
- Параллельные и последовательные этапы через starts_after
- Кнопка Создать продукт из шаблона → выбор даты старта → пересчёт дат
- При изменении шаблона → существующие продукты обновляются автоматически

## Договорённости
- Drag-and-drop НЕ делаем — даты редактируются через input type=date
- Шаблон один (не множественные)
- Anon key в коде — ок для внутреннего инструмента
- Дизайн в конце, после стабилизации структуры
- Фон страницы #bdf4dd — добавить в конце
- История изменений через updated_at — достаточно на старте
- При изменении шаблона пересчитываются только plan_start и plan_end, fact_start и fact_end не трогаем
- Пользователь создаёт гант из шаблона: задаёт дату старта, название продукта, производителя, исполнителей (роль + имя). Статусы и фактические даты проставляет в процессе.
- Массовое присвоение статусов — в бэклоге, не реализуем сейчас
